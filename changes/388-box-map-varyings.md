- Draw the plain lit frame faster (issue #388): the fragment shader now reads the three box-mapping varyings (`boxPosition`, `boxNormal`, `boxNormalMatrix`) only when a material sets `boxMapScale`, so a scene without box mapping no longer makes every vertex compute and pass 15 floats it never uses. On the GPU the main pass of the plain Lakeside, Old church and Warehouse worlds at 1920x1080 drops by 0.2 to 0.5 ms per frame, and the 16 bit target, the MSAA resolve and the post pass turn out to cost 0.3 ms of the 3.3 ms. Output is byte identical on the reference scenes. `entry:core` and both goal scenes get 18 to 20 bytes smaller.
