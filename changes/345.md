- Measure tool schema and result bytes against the base branch with `npm run tool-cost` (issue #345). A pull request that grows a tool by more than 64 bytes, a result by more than 128 or the total by more than 128 accepts it in its own `changes/<issue>.size.md`, so `bench/tool-cost-budgets.json` no longer conflicts. The `measured` history string is gone and the absolute budgets are release ceilings, refreshed by `npm run tool-cost:release`. The npm archive is measured the same way (issue #337): it may grow by 2% of the base branch archive, and an `archive` line in a size note accepts more, so one stale ceiling no longer fails every later pull request.
