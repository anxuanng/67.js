- `loadGltf` and `parseGltf` skip a degenerate triangle primitive instead of throwing for the whole file (issue #481). A missing or short POSITION accessor, a bad index count, an index out of range and a primitive of only zero-area triangles each give one entry in `asset.warnings` that names the mesh, the primitive index and the reason. The file throws only when no primitive survives, and the error lists the skipped ones. A vertex with no generated normal because no triangle with area uses it no longer stops the primitive.
