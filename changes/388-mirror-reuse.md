- Draw a world with water faster when the sky is a large environment map (issue #388): the check that decides whether the water mirror picture can be reused no longer walks the sky's pixels one by one every frame, so a still frame of the container port no longer spends about 170 ms of CPU on it. A typed array of more than 65,536 values in a frame (a sky or texture payload) is now compared by identity; smaller ones, such as the eye position, still compare by value.
