- Keep KTX2 textures GPU-compressed (closes #304). A KTX2 loader that transcodes to BC7, BC1, BC3, ASTC 4x4 or ETC2 is now accepted, and the renderer uploads each mip with `compressedTexSubImage2D`, so a 2K map takes about a quarter of the memory of RGBA8. The new `ktx2WorkerConfigFor(context)` export gives the loader the formats a context takes, and it falls back to RGBA8 where there are none. `asset.textureFormats` lists the format, size and bytes of each texture, and compressed KTX2 images count a quarter of their pixels toward `maxTexturePixels`.
