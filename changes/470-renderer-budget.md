- `Renderer67` sizes its memory budget to the scene when `memoryBudgetMiB` is not passed: room for the geometry, textures and one full frame, at least 256 MiB, at most 1024 MiB on a device that reports 8 GiB of memory or more (512 MiB otherwise). Large exports such as a 234 MB warehouse and a 244 MB paint studio now draw with no options (issue #470). Pass `memoryBudgetMiB` to keep a fixed budget.
- Memory budget errors name the geometry, texture and frame bytes they counted and the `memoryBudgetMiB` that fits, ending in `Fix: pass { memoryBudgetMiB: 365 }`, like the glTF limit errors.
- When `maxTexturePixels` scales textures down, base color and emission maps keep twice the size of the normal, roughness and occlusion maps, for the same memory. The warning names three scaled images and a count; `asset.scaledTextures` still lists every one.
