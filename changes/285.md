- Add outlines, toon light and polylines (part of #285). `environment.lines: {}` draws outlines of fixed pixel width at silhouettes, part boundaries, creases and depth jumps from the object ID, normal and depth guides. `lines.polylines` draws screen-width lines in the world, and `toon` on a material (or `lines.toon`) bands the light. A recipe turns it on with one `set-environment` edit through MCP, and `scene_capabilities` reports `lineArt`. The code is the new addon `@codepawlhq/67js/addons/line-art`, loaded only by recipes that use it, and a scene without `lines` draws as before. Guide: `docs/line-art.md`.
