- entry:spume: spume draws liquid and foam, so it now carries the liquid shader and pass that left the core bundle; every scene without liquid stops paying for them.
- entry:ground-bounce: the ground bounce registers the environment map builder, which moved out of the core bundle with its lookup GLSL.
- entry:hdri: the HDRI entry registers the environment map builder and shading that moved out of the core bundle.
- archive: the liquid and splat shaders ship as two addon files with their own entry chunks, so the package grows by about 2.8 KB while every scene that does not use them loads less.
