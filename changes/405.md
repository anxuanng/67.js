- Add user post-process passes (part 1 of issue #405). A scene can run its own full-screen GLSL ES 3.00 passes on the finished frame, through the `67js/addons/user-pass` addon (`installUserPasses`, `renderer.userPasses.set`), the `postPasses` recipe section and the `set-post-passes` operation. A pass reads `sceneColor`, `sceneDepth`, `resolution`, `time` and `worldNormalAt`, takes named float, vec2 to vec4 and int uniforms, and can render at a `scale` below 1 and enlarge with nearest filtering for a pixel-art look. MCP accepts no host code; a snippet passes `src/shader-snippet-validator.js` first (at most 4 passes of 4 KB, no `#` lines, no `while` or `do`, only counted `for` loops over integer literals up to 64 iterations, no `gl_` names but `gl_FragCoord`, no `u67_` names, at most 16 numeric uniforms) and every refusal carries the line, the column and a fix. A compile failure comes back as `renderError` with the driver log mapped to snippet lines, and the session stays usable. `scene_capabilities` lists the limits under `postPasses`, `scene_inspect` lists the passes, and `docs/user-passes.md` has the API and a dither plus pixel downscale example. The validator is a separate module so the material fragment hook (part 2) can reuse it.
