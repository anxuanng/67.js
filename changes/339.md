- Add `renderer.updateTexture(descriptor, { image?, region? })` in the `texture-update` addon (issue #339). It pushes new pixels into an uploaded texture, such as a live canvas, a video frame or a simulation tile, with `texSubImage2D`. It keeps the sRGB or linear storage and `flipY` of the first upload, regenerates mipmaps and throws clear errors for a wrong size, a region outside the texture, a compressed texture or a descriptor that was never uploaded. The core entry grows by 50 bytes gzip. Recipes and MCP tools have no pixel input yet, so they are unchanged.
