- Names and kinds the caller picks now reach only their own table entry, never one inherited from `Object.prototype`. A mesh attribute named `__proto__`, `constructor` or `prototype` throws a TypeError. A cloth collider of an unknown kind throws a TypeError that lists ball, capsule and box, and a pinned particle that does not exist throws a RangeError. Baking a pattern of an unknown type throws the same RangeError that normalizing it does (issue #475).
