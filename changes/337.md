- Stop size budget conflicts between pull requests (issue #337). `npm run size` now compares each bundle with the base branch and fails when core or a scene grows by more than 64 bytes gzip, or another entry by more than 2%, unless the pull request adds a `changes/<issue>.size.md` note that names the bundle and the reason. Pull requests no longer edit `bench/size/budgets.json` or `baseline.json`, and `npm run size:release` resets them at release. The base is measured beside the pull request and cached by base commit, and the measurement itself runs four builds at once.
