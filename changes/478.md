- Add mesh blend (`67js/addons/mesh-blend`, issue #478), a screen-space pass that softens the seam where one mesh cuts into another (a rock sunk into terrain, a trunk into the ground). A part opts in with `blend: { radius }` in metres, as a part option in code or a `blend` field on a recipe node (MCP `set-node` takes it too). The pass finds seams from the object ID render pass (part change), the frame depth (a depth match, so silhouettes against the sky are skipped) and a normal discontinuity rebuilt from the depth, then mixes the other part's colour over the radius. It adds nothing to the core entry and is off unless a part has `blend`: frames of scenes without it are pixel-identical to main (max difference 0 on a lit box and on a nature terrain). It costs one extra object ID draw plus a fullscreen pass; `docs/mesh-blend.md` has the numbers and limits, and `bench/reference/mesh-blend.mjs` renders the before and after still.
