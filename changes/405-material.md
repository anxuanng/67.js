- Add the material fragment hook (part 2 of issue #405). A recipe material gets an optional `snippet`: `{ fragment, uniforms, mask }`, where `fragment` defines `void materialHook(inout vec3 color, inout float alpha, vec2 uv, vec3 worldPosition)` and may change the colour and alpha or `discard`. It works from `scene_create` and `set-material` (`snippet: null` clears it); no new MCP tool and no host code. The hook runs in the colour pass, in the shadow pass (a discarded fragment casts no shadow) and in the ID pass. `mask: "map"` lets the snippet sample `snippetMask`, the material's own map or pattern. The snippet passes the same validator as a post pass (4 KB, no `#` lines, no `while` or `do`, counted `for` loops, no `gl_` or `u67_` names, at most 16 finite uniforms), every refusal names the line, the column and a fix, and a compile failure returns `renderError` with the log mapped to snippet lines before the running renderer is touched. `scene_capabilities` lists the limits under `materialSnippet`, and `docs/user-passes.md` has a dissolve example. The code lives in the lazy `src/material-snippet.js`, loaded when a recipe contains a `"snippet":{`. Closes #405.
