- Add `applyFloorSkyVisibility` (`67js/addons/floor-sky-visibility`, issue #197), an opt-in trace of the sky each floor texel sees: 64 cosine-weighted rays per texel against the other parts, written into the floor's `skyVisibility`, which the shader already multiplies into the world and sky light. It adds nothing to the core entry, is off unless called, and leaves closed rooms alone unless `includeClosedRooms` is set. On the reference suite it improves 5 scenes by 0.004 to 0.010 FLIP (`car-paint`, `material-spheres`, `brushed-film`, `brick-flat`, `brick-graph`) and the three grand temple options by 0.011 to 0.021, but `long-street` gets worse by 0.0135 and three more scenes pass 0.002, so it is not on by default. The trace takes 0.5 to 1.7 s and the cut floor adds 0.1 to 0.3 ms per frame. The README has the numbers.
