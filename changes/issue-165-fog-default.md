- An unset `volumeFog.shadowAmbient` is now derived from the scene instead of fixed at 0.15. Pass `skyOpenness` from `src/closed-room.js` to `Renderer67` (the agent preview and the reference harness do) and it shoots 32 upward rays from the middle of the fog box, once per scene and fog box: a closed room keeps 0.15, open ground under a sky gets 1, a partly covered scene lands between. Without the option an unset value stays 0.15, so existing renderers draw as before. A recipe that sets the value keeps it, and the recipe echo no longer lists `shadowAmbient` when it was unset. The `fog-valley` reference scene no longer sets it and scores the same 0.1855 against Cycles (EEVEE 0.1952); `dark-shaft` and `fog` move by 0.0012 and 0.0014 (better) and `temple-hall` by 0.0015 (worse), the rest are unchanged (part of issue #165).
