- Add `bake.irradianceGrid` (issue #506): an opt-in baked grid of first order spherical harmonics that gives a sunlit closed room the warm multi-bounce light Cycles has. It is traced on the CPU with the bake's ray tracer, stored in one RGBA16F 3D texture and read with one lookup per pixel, so a frame costs no extra ray. It replaces lightmaps for the scene and is off by default. The code is a lazy module (`src/irradiance-grid.js`); the core entry gains one shader slot and one material field.
