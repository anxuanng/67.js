- entry:agent-scene: the recipe reads a material subsurface block (a field name and a lazy loader line) and scene_capabilities names it.
- entry:agent-scene+lazy: the subsurface addon loads lazily for a recipe that has a subsurface block.
- scene:agent-scene: the same recipe field, lazy loader and capabilities line as entry:agent-scene.
- scene:agent-scene+lazy: the subsurface addon loads lazily, as in entry:agent-scene.
- archive: the subsurface addon (shader, limits) and docs ship in the package.
- tool-total: the material schema gains one subsurface block (weight, radius, scale, color) that scene_create, scene_apply and scene_create_asset each carry, so an agent can write skin, wax and leaves in one call.
- tool:scene_create: the material subsurface block, about 825 bytes.
- tool:scene_apply: the material subsurface block, twice (add-material and set-material), about 1,650 bytes.
- tool:scene_create_asset: the material subsurface block, about 825 bytes.
- result:scene_capabilities: one line naming the subsurface block, with the ranges kept in the tool schema.
