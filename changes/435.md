- Load the container port showcase faster (closes #435): its `scene.glb` is now meshopt-compressed, 24.3 MB to 11.9 MB with identical vertex data, textures and pixels, and the showcase page passes the meshopt decoder to the glTF loader. On a 7.4 Mbps link (the speed the live site delivered, throttled in headless Chrome) the scene is ready in 16.9 s instead of 29.5 s; the decode costs about 0.8 s on a fast link (1.6 s to 2.5 s with the file on localhost). Before this change the live site served the GLB uncompressed (`model/gltf-binary` is not compressed in transit): 22.6 s to ready, 25.5 MB over 23 requests, 92% of it waiting on the network and about 1.7 s on glTF decode and scene build.
