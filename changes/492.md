- The MCP asset catalog takes GLB files up to 64 MiB and 1,000,000 vertices (was 16 MiB and 250,000), and all its limits come from one module, `src/agent-asset-limits.js`, which the catalog, the runtime, the preview page and the render jobs share. A file over a limit fails with an error that names the limit and the value it hit. The limits stay below the `loadGltf` defaults because the file crosses one browser call as base64, which crashed the page from 80 MiB in a local Chrome test (#492).
