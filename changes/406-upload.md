- The renderer starts every program, then uploads textures and buffers, then reads the link results, so the driver links while the upload runs (issue #406). On the AIS port film this hides about 0.25 s; with `ImageBitmap` images (64 ms to upload a 24-megapixel texture against 300 ms from an `Image`) the page loads in 2.8 to 3.4 s instead of 3.6 to 3.7 s. Pixels are unchanged. `docs/terrain.md` has the bitmap loading line and a migration snippet for per-vertex mask samplers.
