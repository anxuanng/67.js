- Show unreleased changes on the site (issue #482). The site build now writes `/changelog.json` (`{ version, released, unreleased }`, each entry with its issue number and a `breaking` flag) and puts an "Unreleased" section above the released ones in `/changelog.md`, both read from `changes/*.md` and `CHANGELOG.md`. A new `changelog.html` page shows them with a link to each issue and an icon on breaking entries, and `docs/mcp.md`, `docs/agent-scene.md` and the `build-67js-scene` skill point agents at the JSON. `.github/workflows/publish.yml` also creates the `v<version>` tag and a GitHub Release from that version's `CHANGELOG.md` section after `publish:ci`, and skips a release that already exists.
