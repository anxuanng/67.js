- entry:agent-scene+lazy: the on-demand vegetation module loads the tree generator, species, bark and leaf textures that a recipe vegetation node grows; nothing loads without a vegetation field.
- entry:agent-asset+lazy: the same on-demand vegetation module, reached through the shared agent scene chunk list.
- scene:gltf-box: the wind heading uniform in the world material shader and renderer, 70 bytes against an allowance of 64.
- scene:gltf-box+lazy: the same wind heading uniform, 70 bytes.
- scene:agent-scene: the vegetation node validation, the generated-part merge in the scene, the environment.wind field and the capabilities text that describes them; the tree generator itself loads on demand.
- scene:agent-scene+lazy: the on-demand vegetation module and the tree generator it loads, counted when every lazy module is bundled.
- tool-total: the vegetation node field, the wind environment field and two material tags are schema in scene_create, scene_apply and scene_create_asset; the detail stays in scene_capabilities.
- tool:scene_create: the recipe schema gains the vegetation node field, environment.wind and the foliage and grass material tags.
- tool:scene_apply: node edits and set-environment share those schema pieces.
- tool:scene_create_asset: the asset recipe shares the environment schema with the wind field.
- result:scene_capabilities: the vegetation entry (node fields, levels, season, wind, limits) and the two new material tags, kept here so the tool schemas stay short.
