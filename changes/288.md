- Draw 3D Gaussian splats as an optional addon, `67js/addons/gaussian-splats` (issue #288). It reads a standard 3DGS PLY with a byte and splat count limit (512 MiB and 2,000,000 by default, 4,000,000 at most), and draws the splats after the opaque parts with the depth test against them, no depth write and a CPU counting sort, back to front, through a wrap of `drawBlendBatches` that needs no renderer change. The core bundle is unchanged. `docs/gaussian-splats.md` has the guide and `bench/gaussian-splats/README.md` the frame time and memory at 100,000 and 1,000,000 splats and the comparison with the three.js `GaussianSplat`. Recipes, the MCP server and the asset catalog (GLB only) do not reach it yet.
