- Draw the showcase worlds from a small first part and stream the rest in (closes #445). Each of `public/showcase/port`, `airport` and `datacenter` is now `scene.glb` (the ground and the hero the opening camera frames) plus `scene.rest.glb`, with a 128x64 `sky.preview.hdr` for the first frame. `scripts/split-showcase-glb.mjs` regenerates the split from the one-piece GLB: every compressed vertex stream, texture and material is copied byte for byte, node transforms are kept, and only the shared meshopt index stream is decoded and encoded again (lossless). The page draws the first part, starts the rest the moment it is in, adds it with `replaceParts`, swaps in the full sky and puts the parts back in the one-piece order. The loading chip shows real megabytes from the first request to the last (for example `3.2 of 13.4 MB`, sizes from `Content-Length`). Core size is unchanged (entry:core +0 B); the logic is in `src/showcase.js` and `src/showcase-download.js`.
- Measured in headless Chrome on a local `vite preview` build, cache off, link throttled to 5 Mbps with no added latency, two runs each (`scripts/measure-showcase-load.mjs`). First frame, before to after: port 22.0-22.1 s to 3.9-4.4 s, airport 27.3-27.5 s to 4.2-4.7 s, datacenter 22.8-23.0 s to 4.0-4.1 s. The first frame needs 2.5-2.7 MB: about 0.4 MB of page code and 1.8-2.2 MB of first part. Final frame: port 22.0-22.1 s to 22.1-22.6 s, airport 27.3-27.5 s to 28.7-29.4 s, datacenter 22.8-23.0 s to 22.9-23.1 s. Bytes for the whole world: port 13.39 to 13.43 MB, airport 18.10 to 18.87 MB (its first part shares textures with the ramp equipment, so they travel twice), datacenter 14.04 to 14.09 MB.
- On an unthrottled link the first frame comes at 0.4-0.9 s instead of 1.3-1.9 s, and the final frame at 1.3-3.6 s instead of 1.3-2.0 s (one airport run took 5.0 s on a busy machine), because the rest decodes and joins after the first frame.
- The final frame matches the one-piece render pixel for pixel in all three worlds at the same camera: mean difference 0 and maximum difference 0 (1280x720 for airport and datacenter; the port draws 632x355 there, which its 512 MiB memory budget allows, before and after).
