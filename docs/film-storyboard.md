# Oppenheimer — a 67.js trailer study

A 187-second procedural 3D reconstruction study inspired by [Universal Pictures’ Oppenheimer New Trailer](https://www.youtube.com/watch?v=uYPbbksJxIg). The sets, stylized figures and synthesized score are authored for 67.js. No source footage, dialogue or soundtrack is included. This is an unofficial study, not a photorealistic reproduction.

## Playback and rendering

`FILM_DURATION` is 187. `FILM_SHOTS` lists 33 cuts; `createFilmScenes()` constructs 13 sets once. `sampleFilm(seconds)` is deterministic, rejects non-finite values and clamps to the timeline. It returns camera, scene, sceneTime, grading, fade, flash, explosion progress and title fields.

Only the active set owns GPU resources; the player disposes it before uploading a different set. Sets share mesh identities for instancing. Cameras interpolate within shots; cuts are intentional. Ignition begins at 181 seconds, followed by the title and a fade to black at 187 seconds.

The film uses HDR with 4× MSAA when supported. Export uses one pending frame, FFmpeg backpressure and explicit renderer, browser heap and Node memory guards. Video capture uses JPEG at quality 95; PNG stills remain lossless. The original WAV score is generated by `scripts/score.mjs`. The legacy URL `/media/critical.mp4` serves the replacement film to preserve existing links.
