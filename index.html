Why agents build better 3D in 67js

  • Zero-code MCP loop: scene_create, scene_apply, scene_look and scene_review validate every edit against a strict schema and revision lock.
  • Spatial self-diagnostics: Automatic closed-room detection, surface-normal inspection, contact & ground-clearance checks, and multi-angle contact sheets.
  • Dual render engines: Renderer67 for sub-millisecond WebGL2 frames + Trace67 for deterministic CPU/GPU path-traced stills with OIDN/wavelet denoising.
  • High-craft primitives built in: Screen-space MeshBlend, deterministic PBD Cloth, cascaded shadows, water reflections, and L1 SH light baking.

A scene in a few lines

import { Renderer67 } from '67js';
import { loadGltf } from '67js/addons/gltf';
import { loadHdri } from '67js/addons/hdri';

const { parts } = await loadGltf('/airport.glb');
const map = await loadHdri('/sky.hdr');
const renderer = new Renderer67(canvas, parts, {
  hdr: true,
  ground: false,
  environment: { map },
});

renderer.render({ eye: [58, 31, 84], target: [-8, 3, -18] });
